# AI לעסקים: אוטומציה, סוכנים ומערכות חכמות לעסק

פורטל מדריכים לקורס מעשי לבעלי עסקים: 10 מפגשי זום של 90 דקות, מזיהוי הזדמנויות AI ועד הובלת הטמעה בעסק.

## מה יש בפורטל

- **סילבוס:** מטרות, תוצרי למידה, פירוט המפגשים, דרישות מקדימות וכלים.
- **מערך שיעור לכל מפגש:** חלוקת זמנים, הסבר הנושא דרך דוגמאות עסקיות, והדגמה חיה צעד אחר צעד.
- **מדריך למורה:** מה אומרים ועושים בכל שלב, דגשים, טעויות נפוצות, שאלות צפויות, טיפים לזום ותוכנית גיבוי.
- **תרגילים:** תרגילי כיתה ותרגיל לבית בכל מפגש, עם פתרון לדוגמה למדריך.
- **משוב:** טופס למדריך וטופס למשתתפים, עם ייצוא ל-JSON ול-CSV, ותהליך עדכון וניהול גרסאות.

## צפייה

פותחים את הקובץ [`dist/course-portal.html`](dist/course-portal.html) בדפדפן. זה קובץ אחד עצמאי, שעובד גם בלי שרת.

## עדכון תוכן

התוכן מופרד מהעיצוב:

| מה | איפה |
|---|---|
| פרטי הקורס והסילבוס | `content/courses/<course-id>/course.json` |
| מפגש בודד | `content/courses/<course-id>/lessons/lNN.json` |
| עיצוב והתנהגות העמוד | `template.html` |

אחרי כל שינוי בונים מחדש את הקובץ:

```bash
python build.py
```

הסקריפט מתריע אם מפגש לא מסתכם ב-90 דקות, אם יש בו פחות מ-50% תרגול, או אם חסר בו תרגיל כיתה או תרגיל לבית.

## הוספת קורס

יוצרים תיקייה חדשה תחת `content/courses/` באותו מבנה (`course.json` ותיקיית `lessons`), ומריצים `python build.py`. הקורס החדש מופיע ברשימת הקורסים בראש העמוד.
